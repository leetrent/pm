# Kanban Project Management Application

A single-board Kanban project management web application built with Next.js, TypeScript, and Vanilla CSS.

## Features
- Single board with 5 renameable columns
- Card creation, editing, and deletion with title and details
- Drag and drop interface to move cards between columns
- Initial dummy data populated
- Client-rendered without persistence

## Getting Started
Navigate to the frontend directory:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Testing
- Unit tests: `npm test`
- End-to-end integration tests: `npm run test:e2e`
- Production build verification: `npm run build`
